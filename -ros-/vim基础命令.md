# Vim 基础命令

Vim 是 Linux 终端中常用的文本编辑器。使用 Vim 最重要的是理解不同的操作模式。

## 一、打开文件

~~~bash
vim 文件名
~~~

例如：

~~~bash
vim keyboard_control.py
vim "git基础命令.md"
~~~

如果文件不存在，Vim 会新建该文件。

## 二、Vim 的三种常用模式

### 1. 普通模式

打开 Vim 后默认进入普通模式，用于移动光标、删除、复制、粘贴和执行命令。

按 Esc 可以回到普通模式。

### 2. 插入模式

用于输入和修改文字。

在普通模式下按：

- i：在光标前插入
- a：在光标后插入
- I：在当前行开头插入
- A：在当前行末尾插入
- o：在当前行下面新建一行并开始输入
- O：在当前行上面新建一行并开始输入

### 3. 命令模式

在普通模式下按冒号进入，用于保存、退出、搜索和替换。

## 三、保存与退出

先按 Esc，确保回到普通模式，然后输入以下命令并按回车：

~~~vim
:w       保存文件
:q       退出 Vim
:wq      保存并退出
:x       保存并退出
:q!      不保存，强制退出
:w!      强制保存
~~~

最常用的退出方法：

~~~vim
:wq
~~~

如果只是查看文件、不想保存修改：

~~~vim
:q!
~~~

## 四、光标移动

在普通模式下：

~~~text
h        向左
j        向下
k        向上
l        向右
~~~

常用快速移动：

~~~text
0        移动到行首
^        移动到行首第一个非空字符
$        移动到行尾
gg       移动到文件开头
G        移动到文件末尾
:n       跳转到第 n 行
Ctrl + f  向下翻页
Ctrl + b  向上翻页
Ctrl + d  向下翻半页
Ctrl + u  向上翻半页
~~~

例如跳转到第 20 行：

~~~vim
:20
~~~

## 五、删除

在普通模式下：

~~~text
x        删除光标所在字符
dd       删除当前行
ndd      删除从当前行开始的 n 行
D        删除光标到行尾的内容
dw       删除一个单词
d$       删除光标到行尾
~~~

例如删除 3 行：

~~~text
3dd
~~~

## 六、复制与粘贴

在普通模式下：

~~~text
yy       复制当前行
nyy      复制 n 行
p        粘贴到光标后或下一行
P        粘贴到光标前或上一行
~~~

例如复制 3 行：

~~~text
3yy
~~~

## 七、撤销与恢复

~~~text
u        撤销上一步操作
Ctrl + r  重做被撤销的操作
.        重复上一次操作
~~~

## 八、搜索

在普通模式下：

~~~text
/关键词   向下搜索
?关键词   向上搜索
n        查找下一个
N        查找上一个
~~~

例如搜索 keyboard：

~~~vim
/keyboard
~~~

按 Esc 可以退出搜索输入状态。

## 九、替换文字

只替换当前行第一个匹配项：

~~~vim
:s/旧内容/新内容
~~~

替换当前行全部匹配项：

~~~vim
:s/旧内容/新内容/g
~~~

替换整个文件中的所有匹配项：

~~~vim
:%s/旧内容/新内容/g
~~~

替换整个文件，并逐项确认：

~~~vim
:%s/旧内容/新内容/gc
~~~

确认时：

- y：替换
- n：跳过
- a：全部替换
- q：退出替换

## 十、可视模式

可视模式用于选择文字。

在普通模式下：

~~~text
v        按字符选择
V        按行选择
Ctrl + v  按矩形区域选择
~~~

选择后可以执行：

~~~text
d        删除选中内容
y        复制选中内容
p        粘贴
~~~

## 十一、显示行号

显示行号：

~~~vim
:set number
~~~

关闭行号：

~~~vim
:set nonumber
~~~

也可以简写为：

~~~vim
:set nu
:set nonu
~~~

## 十二、常见编辑操作

~~~text
J        将下一行合并到当前行
r字符     替换当前光标处的一个字符
cw       修改一个单词
cc       删除当前行并进入插入模式
C        修改光标到行尾的内容
~        切换字母大小写
>>       当前行向右缩进
<<       当前行向左缩进
~~~

## 十三、同时执行多个命令

常用命令：

~~~vim
:set number
:w
~~~

也可以在终端中直接打开文件并跳转到指定行：

~~~bash
vim +20 文件名
~~~

## 十四、Vim 的基本操作流程

### 打开并修改文件

~~~bash
vim 文件名
~~~

进入 Vim 后：

1. 按 i 进入插入模式
2. 输入或修改内容
3. 按 Esc 回到普通模式
4. 输入 :wq
5. 按回车保存并退出

### 只查看文件

~~~bash
vim 文件名
~~~

查看完成后：

~~~vim
:q!
~~~

## 十五、最需要记住的命令

~~~text
i        开始编辑
Esc      回到普通模式
:w       保存
:q       退出
:wq      保存并退出
:q!      不保存强制退出
dd       删除一行
yy       复制一行
p        粘贴
u        撤销
/关键词   搜索
~~~

## 十六、遇到 Vim 不会退出怎么办

如果屏幕上正在输入文字：

1. 先按 Esc
2. 输入 :q!
3. 按回车

这会放弃本次修改并退出 Vim。需要保留修改时，使用 :wq。
