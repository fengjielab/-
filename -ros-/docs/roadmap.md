## 01：麦克纳姆轮结构和运动方向

### 目标

理解四个轮子的安装方向、滚子方向和前进、横移、旋转之间的关系。

### 已有资料

- 两版麦克纳姆轮照片。
- 轮子朝向推导图。
- 车架和接线图手稿。

### 完成标准

- 能画出四个轮子的编号和正方向。
- 能解释每个轮子在前进、横移、旋转时的运动方向。
- 能把轮子方向定义转换成电机方向和编码器符号。

## 02：四轮运动学

### 前置条件

完成轮子编号、车体坐标系和正方向定义。

### 目标

建立 `vx`、`vy`、`wz` 到四个轮速的映射，理解正运动学和逆运动学。

### 完成标准

- 给定 `vx`、`vy`、`wz`，可以计算四个目标轮速。
- 通过仿真或实际测试验证前进、横移和原地旋转。

## 03-06：STM32 底层控制和通信

### 目标

将当前已经完成的 PWM、方向、编码器和 PID 功能整理成稳定的底层驱动，并定义上位机可以调用的串口协议。

### 完成标准

- 有明确的电机编号、速度单位和符号约定。
- 有串口帧格式、校验方式和错误处理说明。
- 能通过串口发送四轮目标速度并获得实际速度反馈。
- 关键参数和测试结果可以在项目 README 中复现。

## 07：Linux/Jetson 与 STM32 通信

### 前置条件

完成串口协议，并确认 STM32 能稳定接收和反馈数据。

### 完成标准

- Linux 端能够打开串口并周期性发送目标速度。
- 能处理断线、乱码、超时和急停。
- 能记录通信延迟和控制周期。

## 08：ROS 节点和 `cmd_vel`

### 前置条件

完成 Linux/STM32 通信程序和四轮运动学。

### 完成标准

- ROS 节点订阅 `cmd_vel`。
- 将 `vx`、`vy`、`wz` 转换为四轮目标速度。
- 将目标速度发送到 STM32，并能观察实际反馈。

## 09-10：里程计、IMU、SLAM 和导航

### 前置条件

完成轮速反馈、车体运动学、通信和 ROS 控制链路。

### 完成标准

- 根据轮速计算里程计。
- 融合 IMU 与轮速数据，减少姿态和位置漂移。
- 在已知环境中完成建图。
- 使用导航栈完成目标点移动和避障测试。

## 11：完整系统重构

### 目标

不依赖幻尔已经封装好的核心控制代码，独立完成从 `cmd_vel` 到四个电机，再到里程计、建图和导航的完整链路。

### 完成标准

- 能独立解释每一层的输入、输出和数据格式。
- 能从零创建工程并复现主要功能。
- 有完整的架构图、测试记录、问题记录和版本标签。
